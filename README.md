## Publish a blog post

Create a Markdown file named `_posts/YYYY-MM-DD-unique-slug.md`. Use the
publication date in the filename and choose a lowercase slug with hyphens that
hasn't been used for another post.

```markdown
---
title: "My post title"
---

Write the post here using Markdown.
```

Merge the post into `master`. GitHub Pages builds the article at
`https://ashton.website/blog/unique-slug/` and adds it to the
[blog index](https://ashton.website/blog/). Keep the filename's slug stable
when editing a published post so its link keeps working.
